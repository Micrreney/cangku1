# cangku1 — 正则表达式 Regex 作业

## 作业要求

- 文件名：`url.html`
- 要求：使用 regex 正则技术（参考《正则表达式 Regex》课件规范）
- 效果：将文件中的超链接地址和链接标题，匹配提取出来，打印输出

## 实现说明

代码文件：`url_regex.c`（C 语言，Linux 平台）

按照课件规范实现：

1. **数据源加载**：`open` + `lseek` + `mmap` 将磁盘上的 `url.html` 整个映射到进程内存，通过 `mmap_ptr` 直接访问文件数据
2. **正则编译**：`regcomp` 将正则语句字符串转换为正则类型 `regex_t`（`REG_EXTENDED` 扩展模式）
3. **循环匹配**：`regexec` 调用一次匹配一条结果，成功返回 0，失败返回 `REG_NOMATCH`，用 `while` 循环从上次匹配结束处持续向后匹配
4. **提取数据**：正则数量 = 括号数 + 1，本例 2 对括号 → `regmatch_t match[3]`：
   - `match[0]`：整体匹配（`<a ...>...</a>`）
   - `match[1]`：子表达式 1 —— 超链接地址
   - `match[2]`：子表达式 2 —— 链接标题
5. **释放资源**：`regfree` 释放正则类型，`munmap` 解除内存映射，避免内存泄漏

## 正则语句

```regex
<a[[:space:]]+[^>]*href="([^"]+)"[^>]*>[[:space:]]*([^<]+)</a>
```

- `[^"]+`：地址关键表达式，匹配引号内非引号内容，天然规避贪婪越界
- `[^<]+`：标题关键表达式，匹配 `>` 与 `</a>` 之间的非标签内容，空标题的 `<a></a>` 自动跳过
- `[^>]*`：兼容 `class="ptv"`、`target="_blank"`、`title="..."` 等属性变体

## 编译与运行

```bash
gcc url_regex.c -o url_regex
./url_regex url.html
```
